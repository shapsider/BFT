# Balanced Fine-Tuning · NeurIPS 2026 project page

Buildless, responsive research page for **Aligning LLMs with Biomedical Knowledge using Balanced Fine-Tuning**.

Expected project URL: https://shapsider.github.io/BFT/

## Publish

Upload this directory's contents to the root of the public `shapsider/BFT` repository. In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.

This is the project-page repository. The training code remains at https://github.com/TencentAILabHealthcare/BFT.

## Edit

- `index.html`: paper content, author list, links, citation.
- `style.css`: responsive layout and visual styling.
- `script.js`: figure enlargement, citation copy, and local-confidence illustration.
- `assets/`: original paper figures, author-supplied logos, poster PDF and PPTX.

The numerical summary uses the three-decimal VCWorld values from the supplied camera-ready Results section. Do not silently substitute the rounded two-decimal table values. Figures are original paper assets. Logos were supplied by the author.

## Poster reference

The editable poster adapts the official `pptTemplate.pptx` supplied by the author from https://drive.google.com/drive/u/1/folders/16tSJGJryd7NgQCBblaKxTfXLZXDIJJrt. It retains the 36 × 24 inch landscape canvas (3:2), three-column grid, Arial typography, and original NeurIPS conference logo. Institutional logos are limited to Tencent and Tencent AI for Life Sciences Lab.

Conference uploads follow https://wiki.eventhosts.cc/en/reference/posteruploads:

- Entire poster: PNG, landscape, maximum 5120 × 2880 pixels and 10 MB. Delivered at 4320 × 2880 with an opaque white background.
- Paper thumbnail: PNG, maximum 320 × 256 pixels and 5 MB. Delivered at 320 × 256 from the BFT gene-embedding UMAP in Figure 4a, with an opaque white background.

The project page provides both upload images, an editable PPTX, and a print PDF. It does not submit them to the NeurIPS account.
